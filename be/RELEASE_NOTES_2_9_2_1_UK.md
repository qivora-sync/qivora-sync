# QIVORA Backend 2.9.2.1

## Виправлення
- Узгоджено внутрішню версію `package.json` з версією архіву: `2.9.2.1`.
- У транзакціях створення/заміни та відкликання коду запрошення блокування заявок і коду виконується в тому самому порядку, що й під час рішення власника. Це зменшує ризик deadlock при одночасному підтвердженні та відкликанні запрошення.
- Додано статичні перевірки порядку блокувань у тестах shared access.

## Перевірки
- `npm run test:all` — успішно.
- `npm run test:record-sync` — успішно (запуск із кореня `be/` у структурі репозиторію, де поруч є `fe/`).
- Frontend family-code-invites: 18 перевірок — успішно.

## Межі перевірки
Цей реліз не пройшов інтеграційний тест на окремій реальній PostgreSQL та наскрізний тест двох окремих акаунтів у розгорнутому Render-сервісі. Перед production deployment потрібна перевірка на тестовій базі даних.
