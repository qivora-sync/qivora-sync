# QIVORA Backend 2.9.2.5 — сімейний realtime та захист переказів

- Додано автентифікований SSE endpoint `/workspace/sync/events`; workspace визначається сервером через активне членство.
- PostgreSQL LISTEN/NOTIFY тепер надсилає wake-up події підписникам відповідного сімейного простору.
- Heartbeat повторно перевіряє активне членство та закриває потік після втрати доступу.
- Сервер відхиляє неповні або некоректні пари сімейного переказу до запису.
- Перевірки не замінюють production інтеграційний тест на реальній PostgreSQL і двох акаунтах.
