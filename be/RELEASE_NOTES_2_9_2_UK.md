# QIVORA Backend 2.9.2 — посилення кодових запрошень

- Додано стійкі DB rate limits для введення коду: ліміт на акаунт і IP.
- Серверний store серіалізує критичні операції на рівні користувача через PostgreSQL advisory transaction locks.
- Повторна заявка того самого користувача не створює дубль.
- Рішення власника повторно перевіряє стан, строк дії та одноразовість коду в транзакції.
- Після схвалення інші pending-заявки за цим кодом відхиляються.
- Власник бачить псевдонімізований ідентифікатор заявника замість email.
- Відкликання коду в транзакції також закриває pending-заявки.
- Схема даних і особисті фінансові записи не видаляються та не переносяться цим оновленням.

Перевірки: `npm run test:all`, синтаксична перевірка. Живий інтеграційний тест із PostgreSQL не виконувався.
