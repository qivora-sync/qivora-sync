# Backend 2.9.2 — інструкція розміщення

Вміст цього архіву призначений для каталогу `be/` у репозиторії. Не створюйте `be/be`.

Render:
- Root Directory: `be`
- Build Command: `npm install`
- Start Command: `npm start`
- Auto-Deploy: On Commit

Оновлення адитивне: таблиці сімейного простору створюються `initDb()` через `CREATE TABLE IF NOT EXISTS`; міграції персональної та workspace-синхронізації не видаляються. Перед розгортанням обов'язково зробіть резервну копію PostgreSQL.

Перевірка після розгортання:
1. У Render Events підтвердити новий deploy.
2. У Logs перевірити `qivora-sync@2.9.2 start` та успішний запуск БД.
3. Перевірити API на двох тестових акаунтах.
4. Перевірити повторне використання коду, ліміт спроб, відхилення, відкликання та строк дії.

Увага: у цій збірці не виконано live integration test на реальній PostgreSQL. Не вважати її production-verified до проходження ручного тест-плану.
