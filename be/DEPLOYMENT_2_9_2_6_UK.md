# Розгортання QIVORA Backend 2.9.2.6

1. Спочатку розгорнути на окремому staging-сервісі, не на production.
2. Переконатися, що Render використовує Node.js 20 або новіший.
3. Встановити залежності з `package-lock.json` (якщо він використовується у deployment).
4. Запустити `npm run test:all` із кореня `be` у release-структурі, де `fe` розташована поруч із `be`.
5. Перевірити `/health`.
6. На staging створити простір, запросити двох користувачів, підтвердити обидва запрошення.
7. Переконатися, що наступне підтвердження відхиляється з HTTP 409 `workspace-member-limit-reached`.
8. Окремо запустити два паралельні запити підтвердження для останнього вільного місця: має активуватися рівно один користувач.
9. Лише після перевірки й окремого дозволу власника можна планувати production deployment.

Ця версія не містить автоматичного деплою та не змінює production.
