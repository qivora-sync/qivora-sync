# QIVORA Backend 2.9.1 — кодові запрошення

- Основний спосіб приєднання до сімейного простору — одноразовий код, що діє 24 години.
- Власник створює код; інший авторизований користувач вводить його; власник підтверджує або відхиляє запит.
- Використовуються `/shared-access/code`, `/shared-access/redeem`, `/shared-access/requests`, `/shared-access/requests/decision` та DELETE `/shared-access/code`.
- Видалено API email-запрошень і залежність від відправлення листів для сімейного доступу. Email OTP для входу в акаунт залишається окремою функцією.
- Таблиці та міграції синхронізації сімейного простору збережені. Особисті дані не видаляються.

Кандидат для перевірки — не розгортати без повного набору тестів і резервної копії БД.
