# QIVORA Backend 2.9.2.5 — інструкція розгортання

У GitHub репозиторії файли Backend мають лежати безпосередньо в каталозі `be/` (тобто `be/server.js`, `be/package.json`, `be/migrations/`). Не створюйте вкладений `be/be/`.

Render:
- Root Directory: `be`
- Build Command: `npm install`
- Start Command: `npm start`
- Node: 20 або новіший
- Auto-Deploy: після перевірки та резервної копії БД

Перед оновленням зробіть резервну копію PostgreSQL. Міграції адитивні; перевірте Render Logs після запуску.

Після деплою обов'язково провести інтеграційний тест двох реальних акаунтів: приєднання, створення сімейного рахунку, доходи/витрати, редагування, видалення, переказ, SSE-повідомлення, повторне підключення та офлайн-відновлення.

Цей архів пройшов локальні автоматизовані тести, але не має підтвердження роботи на production PostgreSQL. Не вважати його повністю production-verified до проходження цього тест-плану.
